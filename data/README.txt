------------------------------------------------------------------------
2. DESCRIPTION
------------------------------------------------------------------------
The dataset contains administrative records of road-traffic incidents
reported by the Secretaría de Movilidad de Medellín between 2008 and 2025.

The analytical focus of the study includes:

- Descriptive statistics of road-traffic incidents
- Identification of fatal incidents
- Differences between incident classes
- Statistical modeling of fatality risk

The dataset enables reproducible statistical analysis of traffic
fatalities in the urban mobility system.

------------------------------------------------------------------------
3. DATASET STRUCTURE
------------------------------------------------------------------------

Main dataset file:
- Fatal_Road_Traffic.xlsx

Each row corresponds to one road-traffic incident.

Key variables include:

- LLAVE: Unique incident identifier
- AÑO: Year of occurrence (2008–2025)
- FECHA_INCIDENTE: Incident date
- HORA_INCIDENTE: Recorded time of incident
- CLASE_INCIDENTE: Incident class
- GRAVEDAD_INCIDENTE: Incident severity
- Latitud: Geographic latitude (WGS84)
- Longitud: Geographic longitude (WGS84)
- Codigo Comuna Planeacion: Planning district code
- Comuna Planeacion: Planning district name
- Codigo Barrio Planeacion: Neighborhood code
- Barrio Planeacion: Neighborhood name

Supporting documentation:

- Data_Dictionary_Fatal_Road_Traffic.xlsx

This file provides:

- Variable names
- English descriptions
- Data types
- Measurement levels
- Units of measurement

4. REPRODUCIBLE ANALYSIS SCRIPT
------------------------------------------------------------------------

File:
- Reproduce_tables_models.R

Description:
This script reproduces the statistical tables and regression model
reported in the manuscript.

Analytical components include:

1. Data cleaning and preprocessing
2. Construction of the fatal incident subset
3. Descriptive statistics of incident classes
4. Frequency tables by planning district
5. Grouped binomial logistic regression model

The logistic regression model evaluates the relationship between
incident characteristics and fatal outcomes.

Model specification:

Outcome variable:
- Fatal vs Non-fatal incidents

Predictors:
- Incident class
- Time-of-day category
- Weekday vs Weekend
- Year of occurrence

Outputs generated by the script include:

- Table 1: Database description
- Table 2: Variable summary
- Table 3: Distribution of incidents by class and severity
- Table 4: Top planning districts in the fatal subset
- Table 5: Annual counts of incidents
- Table 6: Missing data diagnostics
- Table 7: Logistic regression results

6. NOTES ON REPRODUCIBILITY
------------------------------------------------------------------------

To reproduce the results:

1. Place the files

   Fatal_Road_Traffic.xlsx
   Data_Dictionary_Fatal_Road_Traffic.xlsx
   Reproduce_tables_models.R

   in the same directory.

2. Open R or RStudio.

3. Run the script:

   Reproduce_tables_models.R

The script will automatically:

- Clean and standardize the dataset
- Generate descriptive tables
- Estimate the logistic regression model
- Export the results for replication purposes.
